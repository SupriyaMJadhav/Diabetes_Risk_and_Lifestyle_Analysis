# Diabetes_Risk_and_Lifestyle_Analysis
An end-to-end data engineering and analytics pipeline. This project preprocesses raw clinical patient data, trains a predictive Machine Learning model achieving **85.4%** accuracy, stores the data in a local SQL Server warehouse, and delivers an executive Power BI dashboard.

### 🚀 Project Overview
This project simulates a professional healthcare data pipeline. It solves the challenge of handling messy clinical data, extracting predictive risk scores using AI, archiving historical records securely in a relational database, and presenting actionable trends to medical administrators.

The Pipeline Architecture
Data Cleaning (cleaning.py): Handles missing values, outliers, and generates synthetic patient visit timelines (Visit_Date) across a 2-year window to enable temporal trend analysis.

Machine Learning (model.py): Utilizes a Scikit-Learn Random Forest Classifier to train on clinical biomarkers (Glucose, HbA1c, BMI, Insulin) and predict patient diabetes outcomes.

Data quaries (sql_queries.sql): Migrates the cleaned dataset using pyodbc for structural analysis and deep-dive data querying.

Business Intelligence (diabetes_dashboard.pbix): Connects to the data warehouse to serve a high-end, clean, and classy KPI executive dashboard featuring patient risk tiers, biomarker tracking, and operational intervention lists.

### 💻 Installation & Local Setup

1. Install Required Dependencies
Ensure you have the Microsoft ODBC Driver for SQL Server installed on your machine, then run:
pip install pandas numpy scikit-learn sqlalchemy pyodbc

2. Run the Data Pipeline
Execute the pipeline stages sequentially to clean the raw data, generate features, and test the machine learning model:
python cleaning.py
python model.py
python connection.py

### 📊 Database Insights (SQL Server)
The database layer processes the structural schema into a patients table within the DiabetesDB ecosystem. Sample production queries include:

High-Risk Intervention Target List:

SELECT patient_id, age, bmi, glucose_level, risk_score
FROM patients
WHERE diabetes_outcome = 0 AND risk_tier = 'High'
ORDER BY risk_score DESC;
Lifestyle vs Biomarker Mapping: Evaluates average glucose levels and general risk scores across different physical activity thresholds to track behavioral outcomes.

### 🎨 Power BI Executive Dashboard
The final dashboard layout is built using a classy, healthcare-focused slate aesthetic. It removes clutter to prioritize immediate clinical decision-making.

Key Dashboard Highlights:
Executive Metrics: High-level overview of total patient influx, average risk distribution scores, and active high-risk percentage changes over a 24-month period using integrated sparkline trend-cards.

Biomarker Clusters: Clustered bar charts tracking HbA1c and Glucose levels grouped by distinct patient age cohorts (18-29, 30-49, 50-69, 70+).

Priority Operational List: A conditional-formatted, interactive target chart enabling hospital administrators to immediately filter high-risk, non-diabetic individuals for preemptive clinical checkups.
